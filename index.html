নিজের কম্পিউটারে চালান

আসল ডাউনলোডের জন্য Python সার্ভারটা লাগে (ব্রাউজার একা YouTube/Facebook থেকে নামাতে পারে না)। Python 3.12+ আর ffmpeg ইনস্টল করে চালান:

pip install -r requirements.txt
python server.py
# Then open http://localhost:8000
